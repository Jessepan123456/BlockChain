# BlockChain
A blockchain implementation featuring proof-of-work mining, transaction management, etc.

## Features
### Blockchain Core
- Custom blockchain implementation
- Difficulty adjustment
- Mining reward system
  
### Transactions
- Create transactions between addresses
- Sender/receiver history
- Calculate balances

### Mining System
- Proof-of-work
- mining reward
- Merkle root generation

## Persistence
- Save to JSON file
- Serialize entire chain
